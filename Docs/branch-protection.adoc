This document describes the branch protection rules configured for the `Pingponeros-SA` repository and the repository files that support them. Branch protection rules are configured in GitHub (Settings > Branches) and are not stored in repository files.

---

== Repository-enforced files

The following files are committed to this repository and provide automation used by branch protection rules:

* `.github/CODEOWNERS` - marks all three team members (`@JM-193`, `@Carlos-Obando-L`, `@SebasGomezCastro`) as required reviewers for every file.
* `.github/workflows/ci.yml` - GitHub Actions workflow that runs ESLint + Prettier (frontend) and `dotnet build` + `dotnet test` (backend) on every push and PR in all branches.

---

== Branch protection rules (GitHub)

The rules below are configured in GitHub and apply to the specified branches.

=== `main`

* Pull requests are required before merging.
* Required approvals: `2`.
* Dismiss stale pull request approvals when new commits are pushed.
* Code owner reviews are required.
* Required status checks must pass before merging.
* Branches must be up to date before merging.
* Required checks:
  ** `Frontend (Lint, Build & Test)`
  ** `Backend (Build & Test)`
* Administrators cannot bypass these settings.

=== `dev`

* Pull requests are required before merging.
* Required approvals: `1`.
* Dismiss stale pull request approvals when new commits are pushed.
* Required status checks must pass before merging.
* Branches must be up to date before merging.
* Required checks:
  ** `Frontend (Lint, Build & Test)`
  ** `Backend (Build & Test)`
